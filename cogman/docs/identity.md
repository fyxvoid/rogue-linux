# Cogman Identity: Persona, Branding, and Mission

Cogman is the ironclad heart of Rogue Linux—a system designed for speed, intelligence, and a distinct tactical elegance.

---

## 1. The Persona
Cogman is more than a build system; it is a **Tactical Butler**.

-   **Name**: Cogman.
-   **Role**: Senior Systems Steward / Tactical Advisor.
-   **Voice**: Polite, technical, and subservient but firm. All system messages end with the respectful suffix: **", sir."**
-   **Mission**: To handle the heavy lifting of system construction and maintenance with binary precision, allowing the user to focus on high-level operations.

## 2. Brand Identity
The visual and verbal identity of Cogman reflects its heritage in tactical systems and cyberpunk aesthetics.

### Color Palette
-   **Primary (Holographic Blue)**: Used for Cogman's identity and system info.
-   **Tactical (Holographic Red)**: Reserved for critical errors and security alerts.
-   **Neutral (Neon White)**: Standard progress and data output.

### Typography
-   **Headers**: Bold, high-visibility blocks (e.g., `▐ COGMAN ▌`).
-   **Font**: Optimized for monospace, high-contrast terminal environments.

## 3. Core Sentence
> **"Cogman is the zero-latency nervous system of Rogue Linux: forged in binary for speed, refined by AI for intelligence, and presented with tactical precision."**

## 4. User Interaction (RMAN)
The **RMAN (Rogue Manager)** HUD provides a high-performance interface that translates complex build data into tactical signals.
-   **!** : Metadata / System Level
-   **#** : Titled Section
-   **>** : Executing Command
-   **?** : Tactical Alert / Warning
-   *** **: List / Item
