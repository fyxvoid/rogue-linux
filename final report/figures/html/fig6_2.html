Zero-allocation read path (cogman-executor):
fd = open(path) → base = mmap(NULL, size, PROT_READ, MAP_PRIVATE, fd, 0) → cast base → struct plan_header* → validate magic + version → index step records as base + 64 + i×128 → resolve strings via base + strtab_offset + field_off
String table deduplication (cogman-planner):
Identical strings (e.g. workdir='/tmp/build' shared by 40 steps) are stored once in the string table. All 40 step records point to the same offset. FNV-1a hash of the full metadata file is used as the plan cache key.
